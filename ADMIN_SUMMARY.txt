================================================================================
                         TROUBLESHOOTING RÁPIDO
================================================================================

"Erro ao fazer login":
  → Verifique credenciais: admin@alessandra.com / Admin123!
  → Execute: npm run setup:admin
  → Limpe localStorage (F12 → Application → Clear All)

"Dados não carregam":
  → Verifique se backend está rodando
  → Verifique conexão com banco
  → Recarregue a página (F5)

"Token inválido":
  → Faça login novamente
  → Tokens expiram em 30 dias

"Mudanças não salvam":
  → Verifique console (F12)
  → Verifique se backend está online
  → Tente novamente
