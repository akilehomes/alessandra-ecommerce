================================================================================
                          COMECE AQUI - ADMIN DASHBOARD
================================================================================

Bem-vindo ao Admin Dashboard do E-Commerce Alessandra Zanetti!

Este arquivo contém as instruções passo a passo para começar em 5 minutos.

================================================================================
                            PASSO 1: PREPARAR BANCO
================================================================================

Abra um terminal e execute:

  cd backend
  npm run setup:admin

Você verá:
  ✅ Admin user created successfully!
  📋 Admin Credentials:
     Email: admin@alessandra.com
     Password: Admin123!

Se isso funcionar, passe para o PASSO 2.

Se der erro "database does not exist":
  • Verifique se PostgreSQL está rodando
  • Crie o banco: createdb alessandra_ecommerce
  • Tente novamente

================================================================================
                          PASSO 2: INICIAR BACKEND
================================================================================

No mesmo terminal (ou abra outra aba), execute:

  npm run dev

Você verá:
  ✅ Database connected
  🚀 Server running on http://localhost:5000

Se aparecer isso, o backend está pronto! Não feche este terminal.

================================================================================
                         PASSO 3: INICIAR FRONTEND
================================================================================

Abra um NOVO terminal e execute:

  cd frontend
  npm start

A aplicação abrirá automaticamente em http://localhost:3000

Você verá a home page do site. Isso é normal!

================================================================================
                          PASSO 4: FAZER LOGIN
================================================================================

1. Clique no navegador e acesse:
   http://localhost:3000/admin/login

2. Você verá a página de login do admin

3. Digite:
   Email: admin@alessandra.com
   Senha: Admin123!

4. Clique "Entrar"

5. Você será redirecionado para o dashboard!

================================================================================
                         PASSO 5: EXPLORAR DASHBOARD
================================================================================

Parabéns! Você está dentro!

Você pode ver:

1. DASHBOARD (aba ativa):
   - Total de Produtos: 0 ou mais
   - Total de Pedidos: 0 ou mais
   - Faturamento: R$ 0,00 (sem pedidos)
   - Status Pendentes: número de pedidos pendentes

2. Clique em "PRODUTOS" para:
   - Criar novos produtos
   - Editar produtos existentes
   - Deletar produtos
   - Gerenciar imagens

3. Clique em "PEDIDOS" para:
   - Ver todos os pedidos de clientes
   - Atualizar status (de Pendente para Pago, etc)

4. Clique em "FRETE" para:
   - Editar tarifas de frete
   - Ajustar preços por região

5. Clique em "IMPOSTOS" para:
   - Ajustar alíquotas por país
   - Ver países pré-configurados

6. Clique em "CÂMBIO" para:
   - Atualizar taxas de conversão
   - EUR, USD, BRL

7. Clique "SAIR" para:
   - Fazer logout
   - Volta para /admin/login

================================================================================
                         PASSO 6: MUDAR SENHA (IMPORTANTE!)
================================================================================

Agora você deve mover a senha padrão.

Infelizmente, a interface atual NÃO tem tela para mudar senha.
Você pode fazer de duas maneiras:

OPÇÃO A - Via Database (PostgreSQL):

  1. Abra um terminal
  2. psql -U postgres -d alessandra_ecommerce
  3. UPDATE admin_users SET password_hash = 'novo_hash' WHERE email = 'admin@alessandra.com';
  
  Para gerar o hash, use Node.js:
    node -e "require('bcryptjs').hash('SuaNovaSenha123', 10, (err, hash) => console.log(hash))"

OPÇÃO B - Criar novo admin via código:

  1. Edite /backend/seed-admin.js
  2. Mude o email, password e fullName
  3. Execute: npm run seed:admin

Depois voltaremos a melhorar a interface!

================================================================================
                          TROUBLESHOOTING RÁPIDO
================================================================================

PROBLEMA: "Erro ao conectar ao banco"
SOLUÇÃO:
  • Verifique se PostgreSQL está rodando
  • Verifique credenciais do .env
  • createdb alessandra_ecommerce
  • npm run setup:admin

PROBLEMA: "Erro 401 ao fazer login"
SOLUÇÃO:
  • Use: admin@alessandra.com (sem espaços)
  • Verifique se digitou a senha correta
  • Limpe localStorage: F12 → Application → Clear All
  • npm run setup:admin novamente

PROBLEMA: "Dashboard carrega mas sem dados"
SOLUÇÃO:
  • Crie um produto de teste primeiro
  • Ou verifique se o banco tem dados

PROBLEMA: "Página em branco após login"
SOLUÇÃO:
  • Recarregue a página (F5)
  • Verifique console (F12 → Console)
  • Verifique se backend está online

PROBLEMA: "Não consigo criar produto"
SOLUÇÃO:
  • Verifique se backend está rodando
  • Verifique console (F12 → Network)
  • Verifique logs do backend
