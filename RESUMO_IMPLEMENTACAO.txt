  ✓ Portugal: 23% (VAT)
  ✓ Europa: 19-22% por país (VAT)
  ✓ Cálculo automático por região
  ✓ Exibição clara no checkout (Subtotal + Imposto + Frete = Total)

CÂMBIO:
  ✓ EUR → BRL: 5.90
  ✓ BRL → EUR: 0.17
  ✓ USD → BRL: 5.00
  ✓ USD → EUR: 0.95
  ✓ API para conversão de moedas
  ✓ Atualização de taxas (endpoint admin)

REGIÕES CONFIGURADAS:
  BR (Brasil):
    - Moeda: BRL
    - Símbolo: R$
    - Imposto: 18%

  PT (Portugal):
    - Moeda: EUR
    - Símbolo: €
    - Imposto: 23%

  EU (Europa):
    - Moeda: EUR
    - Símbolo: €
    - Imposto: 21%

ROTAS DE API (IMPOSTOS):

ROTAS DE API (MOEDA):
  GET    /api/currency/rate            - Taxa de câmbio
  POST   /api/currency/convert         - Converter moeda
  GET    /api/currency/all             - Todas as taxas
  PUT    /api/currency/update-rate     - Atualizar taxa (admin)

COMO USAR
═══════════════════════════════════════════════════════════════════════════════════

1. SETUP BANCO DE DADOS:
   psql -U postgres -d alessandra_ecommerce < backend/database/migration-add-auth.sql
   psql -U postgres -d alessandra_ecommerce < backend/database/migration-shipping-taxes.sql

2. CONFIGURAR .env:
   JWT_SECRET=sua-chave-secreta-aqui
   DB_USER=postgres
   DB_PASSWORD=sua-senha
   DB_HOST=localhost
   DB_PORT=5432
   DB_NAME=alessandra_ecommerce
   PORT=5000
   REACT_APP_API_URL=http://localhost:3001/api

3. INICIAR BACKEND:
   cd backend
   npm run dev

4. INICIAR FRONTEND:
   cd frontend
   npm start

5. TESTAR:
   Frontend: http://localhost:3000
   API: http://localhost:5000/api
   Ver TEST_API_ENDPOINTS.md para exemplos com curl

═══════════════════════════════════════════════════════════════════════════════════
FLUXO COMPLETO DO USUÁRIO
═══════════════════════════════════════════════════════════════════════════════════

1. REGISTRO:
   - Ir para /register
   - Preencher email, senha, nome, telefone
   - Token JWT salvo em localStorage
   - Redirecionado para /account/orders

2. LOGIN:
   - Ir para /login
   - Preencher email e senha
   - Token JWT salvo em localStorage
   - Redirecionado para /account/orders

3. NAVEGAÇÃO:
   - Ver navbar com nome do usuário
   - Clique em "Minha Conta" para ver pedidos anteriores
   - Clique em "Sair" para logout

4. COMPRA (BRASIL):
   - Selecionar região "Brasil" no navbar
   - Adicionar produtos ao carrinho
   - Ir para checkout
   - Preencher endereço (street, number, city, state, CEP)
   - Sistema calcula frete automaticamente
   - Selecionar método de envio
   - Revisar: Subtotal + Imposto (18%) + Frete = Total em R$
   - Preencher dados do cartão
   - Confirmar pagamento
   - Redirecionado para /checkout/success

5. COMPRA (PORTUGAL):
   - Selecionar região "Portugal" no navbar
   - Mesmo fluxo, mas:
     - Aceita código postal português
     - Frete em EUR
     - Imposto: 23%
     - Total em €

6. HISTÓRICO:
   - Ir para /account/orders
   - Ver todos os pedidos realizados
   - Cada pedido mostra: número, status, total, data
